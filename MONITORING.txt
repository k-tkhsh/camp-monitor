■ 運用メモ
------------------------------------------------------------
  - GitHub Actions の schedule は大幅に間引かれる。過去には約7時間
    実行が途絶えたこともあるため、確実性が要る時期は手動実行も併用する。
  - 新しいワークフローファイルは cron 発火の登録に時間がかかる。
    ファイル名を変えると新規ワークフローとして登録し直せる。
  - 人気日程の空きは30分〜1時間程度で埋まる。通知が来たら即予約する。

■ 監視を停止する場合
------------------------------------------------------------
  1. camp_august_monitor.py の WATCHES を [] にする
  2. .github/workflows/camp_watch.yml の schedule / workflow_run /
     push をコメントアウト（workflow_dispatch は残す）
  3. この MONITORING.txt を更新
