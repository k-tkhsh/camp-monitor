# ひらがな あそび — 3〜4歳向けのひらがな学習ゲーム

まだ字が読めない子でも、ひとりで遊びながら ひらがなが読めるようになることを狙った
静的 Web アプリ。指示はすべて **音声と絵** で伝えるので、画面の文字が読めなくても操作できます。
ビルド不要で、データは端末の `localStorage` にだけ保存されます。

## 使い方

```bash
python3 -m http.server 8000     # リポジトリのルートで実行
# → http://localhost:8000/docs/hiragana/ を開く
```

ES モジュールを使っているため、`index.html` を直接ファイルとして開くのではなく HTTP 経由で開いてください。
GitHub Pages（`docs/` 公開）でもそのまま動きます。スマートフォンではホーム画面に追加すると
全画面のアプリとして起動します（PWA・オフライン対応）。

### サーバーを立てられないとき（1ファイル版）

```bash
node docs/hiragana/tools/build-standalone.mjs ~/Desktop/hiragana.html
```

CSS と JavaScript を埋め込んだ 1 枚の HTML を書き出します。ダブルクリックで開くだけで遊べ、
そのまま家族に送ることもできます（`--fragment` を付けると `<body>` の中身だけを出力）。

読み上げには端末の音声合成（Web Speech API）を使います。日本語の音声が入っていない端末では、
音だけが手がかりになる「きいて さがそう」は自動的に休止し、その旨を表示します。

## あそびかた

| メニュー | ねらい | 内容 |
| --- | --- | --- |
| ふうせん わり | 音 → 文字（アクション） | 空にのぼる ふうせんの中から、読み上げられた文字を にげる前に われる |
| なぞりがき | 書き順 | 1画ずつ お手本が動いて、書き順どおりに指でなぞる |
| きいて さがそう | 音 → 文字 | 「あ」と読み上げて、2〜4枚の文字カードから選ぶ |
| はじめの おと | 絵 → 音 → 文字 | 🐜 を見せて「あり」と読み上げ、最初の音の文字を選ぶ |
| ことば パズル | 文字を読む | 「◻︎り」のように 1 文字だけ空いた言葉を見せ、入る文字を選ぶ |
| ひらがな ひょう | 自由に確認 | 五十音表。触ると読み上げ、その字ではじまる絵と言葉が出る |
| ステッカー | ごほうび | 星 10 個ごとに 1 枚もらえるステッカー帳 |

### 小さい子でも遊べるようにした点

- 文字を読ませる指示を出さない。すべて音声・絵・アニメーションで伝える。
- 押しやすい大きなボタン。1 画面の選択肢は最大 4 つ。
- なぞりがき・ふうせんわりの間は ページ自体が動かないようにしている
  （指で下になぞったときに、画面がスクロールしたり 引き下げて閉じたりしないよう
  `touchmove` を直接おさえ、`overscroll-behavior` と併用）。
- **失敗で終わらない**。まちがえたら「もういちど」、2 回目のまちがいで正解を光らせて
  「ありの あ」と教える。先に進めなくなることはない。
- 9 秒さわらないと、もう一度読み上げて うながす（3 回まで）。
- 正解のたびに「せいかい！ ありの あ」と文字と言葉を結びつけて復唱する。
- 5 問ごと・ステッカー獲得・新しい行の開放で、紙吹雪のお祝いが出る。

### ふうせん わり（アクション）

- ふうせんは 地面から ふわりとのぼり、上まで行くと にげてしまう。割った数に応じて 少しずつ速くなる（上限あり）。
- さがしている文字の ふうせんが 画面に無ければ かならず出るので、待ちぼうけにならない。
- ちがう ふうせんを たたいても割れず、ゆれて お手つきを知らせるだけ。減点もゲームオーバーも無い。
- 10個われると おいわい。動く的を追うので、目と指を使いながら 音と文字が結びつく。

### なぞりがき（書き順）

- 1画ずつ、お手本の点が動いて 書き順と向きを見せる。書き始めには ①②③ の番号つきの丸が出る。
- 指でなぞると、線に沿って進んだ割合で判定する。**書き始めの位置・向き・線からのずれ**を見るので、
  ぐるぐる塗っても先に進まない。逆から書いたときは「こっちから かいてみよう」と教える。
- 幼児の指はぶれる前提で、判定はかなりゆるめ。2回つまずくと さらにゆるめて お手本を出し直す。
- 書けた字は 五十音表に ✏️ が付く。書いた回数の少ない字から出題する。
- 読みの習熟度（できる／とくい）とは別に数えるので、なぞっただけで「読める」判定にはならない。

### 出題のしかた

- 最初は **あ行だけ**。その行がひととおりできると、次の行が「あたらしい もじ！」として出てくる。
  1 文字だけ苦手なまま止まらないよう、よく練習して 8 割できていれば先に進む。
- にがてな字・まだ出ていない字ほど出やすい重みづけ抽選。直前と同じ字は続けて出さない。
- まちがい選択肢は **形の似た字を優先**（ぬ/め、わ/ね/れ、さ/き/ち、は/ほ/ま、る/ろ/そ など）。
- 選択肢の数は、できる字が増えるにつれて 2 → 3 → 4 と増える。
- 「を」は「お」と同じ音なので出題しない（表では読み方の説明つきで見られる）。
  「ん」は絵の問題からは外す（その字ではじまる言葉が無いため）。

### 1文字の読み上げ

1文字だけの音は 聞き取りにくいので、次のようにしています。

- 促音をつけず（×「あっ」）、句点で区切って **ゆっくり 2回**（「あ。　あ。」）。くりかえしは設定で切れます。
- 1文字のときだけ 読み上げ速度を大きく落とす（設定の速さ × 0.55、0.35〜0.55 の範囲。
  既定の速さ 0.75 では 約 0.41 倍）。0.35 より遅いと 音がつぶれる端末があるため下限をもうけています。
- 読む前に **「ポン」と合図の音**を鳴らし、少し間を置いてから話す。出だしを聞きのがしません。
- 端末によっては `cancel()` の直後の読み上げで頭が切れるため、話している最中だけ 少し間をあけてから話す。
- 正解やお手本のときも「ありの…」のあとに 1文字をもう一度はっきり読む。

### おうちの人へ（⚙️）

進み具合（まだ／みた／できる／とくい／なぞった）の五十音表、出題する行の指定、効果音の on/off、
読み上げの速さ・くりかえしの有無・声の選択（「あ」で ためし聞きできます）、記録のリセット。

## 書き順データについて

`js/strokes.js` の字形と書き順は **[KanjiVG](https://kanjivg.tagaini.net/)**（Copyright (C) 2009-2011 Ulrich Apel）
を加工したもので、[クリエイティブ・コモンズ 表示 - 継承 3.0 (CC BY-SA 3.0)](https://creativecommons.org/licenses/by-sa/3.0/)
のもとで配布されています。このファイルを再配布・改変する場合は、同じライセンスと出典表示が必要です。
データを取り直すには:

```bash
node docs/hiragana/tools/fetch-strokes.mjs
```

## 構成

```
docs/hiragana/
├── index.html          画面の骨組み
├── styles.css          スタイル（OS のダークモードに追従）
├── manifest.webmanifest / sw.js / icon.svg   PWA 用
└── js/
    ├── data.js         ひらがな46字・絵ことば・似た形のグループ
    ├── strokes.js      書き順データ（KanjiVG 由来 / CC BY-SA 3.0）
    ├── core.js         出題と習熟度の計算（DOM 非依存）
    ├── trace.js        なぞりがきの判定（DOM 非依存）
    ├── action.js       ふうせんの動き（DOM 非依存）
    ├── store.js        localStorage への保存
    ├── audio.js        読み上げ（Web Speech）と効果音（Web Audio）
    ├── balloon.js      ふうせんわりの画面
    ├── write.js        なぞりがきの画面
    └── app.js          画面描画とイベント処理
```

## テスト

`core.js` / `data.js` / `trace.js` / `action.js` のロジックには Node 標準のテストランナーを使ったテストがあります。

```bash
node --test docs/hiragana/tests/*.test.mjs
```
