# NEON BREACH — ブラウザ FPS

ビルド不要・外部ライブラリなしの FPS シューティング。
レイキャスティング（Wolfenstein 3D 方式）を Canvas 2D の ImageData に直接書き込んで描画しています。
テクスチャも敵も効果音もコードで生成しているため、画像・音声ファイルは 1 つもありません。

## 遊び方

```bash
python3 -m http.server 8000     # リポジトリのルートで実行
# → http://localhost:8000/docs/fps/ を開く
```

ES モジュールを使っているため、`index.html` を直接開くのではなく HTTP 経由で開いてください。
GitHub Pages（`docs/` 公開）でもそのまま動きます。

## 操作

| 入力 | 動作 |
| --- | --- |
| `W` `A` `S` `D` / 矢印 | 移動 |
| マウス移動 | 視点（画面クリックでポインタロック） |
| 左クリック / `Space` | 射撃 |
| `Shift` | ダッシュ |
| `1` `2` `3` / ホイール | 武器変更 |
| `M` | ミニマップの表示切替 |
| `Esc` / `P` | ポーズ |

スマートフォンでは画面左半分のドラッグで移動、右半分のドラッグで視点、`FIRE` ボタンで射撃、`⇄` で武器変更です。

## ルール

- ウェーブ制のサバイバル。敵を全滅させると 5 秒のインターバルを挟んで次のウェーブが始まります。
- ウェーブが進むほど敵の体力・速度・攻撃力が上がり、出現数も増えます。
- ウェーブ 2 でショットガン、ウェーブ 3 でサブマシンガンがフィールドに落ちます。
- 敵を倒すと確率で回復キットや弾薬をドロップ。2.5 秒以内に連続で倒すとスコアにコンボ倍率（最大 ×1.75）が付きます。
- ハンドガンは弾切れしません。弾切れの武器で撃とうとすると自動でハンドガンに持ち替えます。
- ハイスコアは `localStorage` に保存されます（端末内のみ）。

| 敵 | 特徴 |
| --- | --- |
| グラント | 標準的な近接型。数で押してくる |
| シューター | 遠距離からプラズマ弾を撃つ。近づくと後退する |
| ブルート | 体力と攻撃力が高い大型。ウェーブ 4 から出現 |

## 構成

```
docs/fps/
├── index.html          画面の骨組みとオーバーレイ（タイトル・ポーズ・リザルト）
├── styles.css          オーバーレイとタッチ操作ボタンのスタイル
└── js/
    ├── core.js         マップ・レイキャスト・当たり判定・敵 AI・経路探索（DOM 非依存）
    ├── assets.js       壁テクスチャと敵スプライトの手続き的生成
    ├── render.js       レイキャスティング描画（床・天井・壁・スプライト合成）
    ├── hud.js          照準・武器の見た目・体力/弾数・ミニマップ
    ├── input.js        キーボード / ポインタロック / タッチ
    ├── audio.js        WebAudio による効果音の合成
    ├── game.js         ウェーブ進行とメインループ
    └── main.js         HTML オーバーレイとの結線
```

### 描画のしくみ

1. 画面の横幅ぶんだけレイを飛ばし（DDA）、壁までの距離からスライスの高さを決める
2. 地平線より上下は床・天井をピクセル単位で逆投影（フロアキャスティング）
3. 敵・アイテム・粒子はビルボードとして、壁の距離バッファ（z-buffer）と比べて手前だけ描く

内部解像度は CSS サイズ × 品質係数で、`自動` 設定ではフレーム時間を見て 0.34〜0.78 の範囲で上下します。

### 敵の経路探索

プレイヤーのいるマスから幅優先探索で距離マップ（フローフィールド）を作り、敵はその勾配を下って追ってきます。
プレイヤーが別のマスへ移動したときだけ作り直すため、28×28 のマップなら負荷はほぼ無視できます。
視線が通っているときは直進しますが、壁の角で進めない場合は経路探索の方向に切り替え、
それでも詰まったら一定時間だけ横に回り込みます。

## テスト

```bash
node --test docs/fps/tests/core.test.mjs
```
