NEON BREACH

崩壊した施設に取り残された。押し寄せる敵をウェーブ単位で撃退しろ。

ハイスコア 0

操作

  • WASD 移動
  • マウス 視点（クリックで視点固定）
  • 左クリック / Space 射撃
  • Shift ダッシュ
  • 123 / ホイール 武器変更
  • M ミニマップ切替　Esc ポーズ

スマホ：画面左半分に指を置くとスティックが出て移動（端まで倒すとダッシュ）。 右半分はドラッグで視点、タップで射撃。FIRE ボタンは押しっぱなしで連射、⇄ で武器変更。

設定

PAUSE

クリック（またはタップ）でゲームに戻る。
