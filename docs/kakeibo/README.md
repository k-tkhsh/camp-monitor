# かけいぼ — 家計簿アプリ

マネーフォワード ME のような家計簿を、ビルド不要の静的 Web アプリとして実装したもの。
データはブラウザの `localStorage` にのみ保存され、外部へ送信されません。

## 使い方

```bash
python3 -m http.server 8000     # リポジトリのルートで実行
# → http://localhost:8000/docs/kakeibo/ を開く
```

ES モジュールを使っているため、`index.html` をファイルとして直接開くのではなく
HTTP 経由で開いてください。GitHub Pages（`docs/` 公開）でもそのまま動きます。
スマートフォンではホーム画面に追加すると全画面のアプリとして起動します（PWA・オフライン対応）。

## 機能

| 画面 | 内容 |
| --- | --- |
| ホーム | 今月の収入・支出・収支（前月比つき）、総資産と口座別残高、支出内訳のドーナツグラフ、予算の消化状況、最近の明細 |
| 履歴 | 種別・カテゴリ・口座・キーワードでの絞り込み、日付ごとの明細一覧と日計 |
| 分析 | 収支の推移（6ヶ月・棒グラフ）、資産の推移（6ヶ月・折れ線）、カテゴリ別ランキングと前月差、中項目別の内訳 |
| 予算 | カテゴリ別の予算設定と進捗バー。毎月の既定予算と「この月だけ」の予算を切り替え可能 |
| 設定 | 口座・カテゴリ・定期的な収支（家賃やサブスク）の管理、月の開始日、CSV / JSON の入出力 |

- **入力**: 支出・収入・振替の 3 種類。金額のクイック加算、中項目のサジェスト、口座の指定に対応。
- **定期的な収支**: 毎月 N 日のルールを登録すると、アプリを開いたときに当日までの明細が自動生成されます（重複登録はしません）。
- **CSV 取り込み**: 本アプリの書き出し形式に加えて、マネーフォワード ME のエクスポート CSV
  （`計算対象,日付,内容,金額（円）,保有金融機関,大項目,中項目,メモ,振替,ID`）を判別して取り込みます。
  Shift_JIS のファイルも自動判定します。`計算対象=0` の行は除外し、振替は符号から出金・入金を判定します。
- **月の開始日**: 給料日締め（例: 25 日始まり）に設定すると、集計期間が 8/25〜9/24 のようにずれます。

## 構成

```
docs/kakeibo/
├── index.html          画面の骨組み
├── styles.css          スタイル（OS のダークモードに追従）
├── manifest.webmanifest / sw.js / icon.svg   PWA 用
└── js/
    ├── core.js         集計・期間計算・CSV などの純粋ロジック（DOM 非依存）
    ├── store.js        localStorage への保存と初期データ
    ├── charts.js       SVG グラフ（外部ライブラリなし）
    └── app.js          画面描画とイベント処理
```

## テスト

`core.js` のロジックには Node 標準のテストランナーを使ったテストがあります。

```bash
node --test docs/kakeibo/tests/core.test.mjs
```
